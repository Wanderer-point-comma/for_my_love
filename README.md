# Одним целым ♡

Личный сайт для пары, который открывается с парных NFC-брелков.
Статический проект: чистые HTML5, CSS3 и Vanilla JavaScript — без сборки, без зависимостей и без сервера.

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html` | Вся разметка страницы (7 секций) |
| `style.css` | Дизайн, адаптив, анимации |
| `script.js` | Плеер, навигация, анимации при скролле |
| `assets/fonts/fonts.css` | Шрифты Caveat + Manrope, встроены в CSS (работают без интернета) |
| `assets/starfield.png` | Звёздное небо в первом экране |
| `assets/card-*.jpg` | Фотографии для карточек-разделов и фотополосы |
| `assets/audio/odnim-celym.mp3` | Наш трек (PHARAOH — Одним целым, 2:45) |

Разделы страницы: **космос (hero)** → **наша вселенная** (5 карточек-навигация) →
**личное сообщение** → **наши места** → **саундтрек** → **наши моменты** → **финал** → подвал.

## Возможности

- Музыкальный плеер: play/pause, громкость (+ отключение по иконке), перемотка и таймкод.
- Кнопка в шапке скроллит к треку и включает/выключает его.
- Музыка никогда не стартует сама — только по действию пользователя.
- Если трек не загрузился — в плеере появляется понятное сообщение об ошибке.
- Полоса прогресса прокрутки, подсветка активного раздела, плавная прокрутка по якорям.
- Появление блоков при скролле, падающая звезда, орбиты, пульсирующее сердце.
- Мобильная версия: нижнее меню- док, адаптив от 320 px, поддержка `safe-area-inset`.
- Полностью офлайн: ни одного внешнего запроса — шрифы, фото и трек лежат рядом.

## Локальный просмотр

Достаточно открыть `index.html` в браузере — всё работает и с диска, и через любой сервер.

Если хочется проверить работу плеера как на хостинге, запусти локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

и открой <http://127.0.0.1:8000/>.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `for-my-love`).
2. Загрузи в него **всю папку целиком** — структура должна быть такой:

   ```
   index.html
   style.css
   script.js
   .nojekyll
   .gitattributes
   README.md
   assets/
     fonts/fonts.css
     audio/odnim-celym.mp3
     starfield.png
     card-places.jpg
     card-words.jpg
     card-music.jpg
     card-memory.jpg
     card-always.jpg
   ```

3. Открой репозиторий → **Settings** → **Pages** → в блоке **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/(root)**
   - нажми **Save**
4. Через 1–2 минуты сайт откроется по адресу:
   `https://<твой-логин>.github.io/<имя-репозитория>/`
5. Проверь, что открылась главная страница, играет трек и видны фотографии.
6. Запиши эту ссылку в оба NFC-брелка.

### Публикация через git (быстрый способ)

```bash
cd путь/к/for_my_love-main
git init
git add .
git commit -m "Одним целым: переработанный сайт пары"
git branch -M main
git remote add origin https://github.com/<твой-логин>/<имя-репозитория>.git
git push -u origin main
```

После `push` включи Pages в настройках репозитория (шаг 3 выше).

> Сайт полностью статический: работает и в корне репозитория, и в подпапке
> (`https://<логин>.github.io/<репозиторий>/`), все пути относительные.

## Персонализация

- Тексты и подписи — в `index.html` (разделы `.section__lead`, `.entry__title`, `.entry__text`, `.message__main blockquote`).
- Цвета и шрифты — переменные в начале `style.css` (`--rose`, `--void`, `--font-script` и т.д.).
- Свой трек: замени файл в `assets/audio/` и поправь `src` у `<audio id="ourTrack">` и подпись `.track__sub`.
- Свои фото: положи файлы в `assets/` и пропиши их в классы `.card__bg--*` / `.strip__img--*` в `style.css`.
- Подпись под именем — `.logo` в шапке.

## Поддержка

Проверено в Chrome/Edge (desktop и mobile-эмуляция), ширины 320 / 360 / 390 / 430 / 768 / 1024 / 1440 px.
Музыка запускается только по клику, громкость и перемотка работают, при отсутствии сети
плеер показывает сообщение об ошибке и не ломает страницу.
