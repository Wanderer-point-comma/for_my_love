# Одним целым — личный сайт для парных NFC-брелоков

Одностраничный сайт в чёрной космической эстетике с красной рукописной типографикой, звёздами и личными сообщениями. Чистые HTML/CSS/JS, без сборки и зависимостей.

## Запуск
Открой `index.html` в браузере.

## GitHub Pages
1. Создай репозиторий GitHub.
2. Загрузи `index.html` в корень репозитория.
3. Settings → Pages → Deploy from a branch.
4. Выбери `main` и `/(root)`, затем Save.
5. После публикации запиши ссылку сайта на оба NFC-брелока.

## Персонализация
- Замени заголовок и текст в `index.html` на ваши личные слова.
- Обнови массив `messages` в конце файла, чтобы кнопка показывала ваши фразы.
- Добавь настоящие места, фотографии и ссылку на вашу песню.
- Верхняя кнопка музыки пока прокручивает к разделу с треком; для автоматического воспроизведения потребуется встроенный плеер и взаимодействие пользователя.

## Публикация на GitHub Pages
Загрузи `index.html` и `Kai_Angel_-_Flowers_82278516.mp3` в одну и ту же папку репозитория (обычно корень). Сайт адаптирован для мобильных экранов, планшетов и компьютеров.
